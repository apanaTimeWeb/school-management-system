# Landing Module Theme Contract

This module depends on the following CSS variables being mapped in `tailwind.config.ts` and defined in `globals.css` or `landing.css`.

## Backgrounds
- `--bg-page` (Main background)
- `--bg-card` (Card/Navbar background)

## Text
- `--text-primary` (Primary headings)
- `--text-secondary` (Subtext)

## Brand Colors
- `--primary` (Main brand color)
- `--primary-hover` (Hover state)
- `--secondary` (Accent color)
- `--secondary-hover` (Accent hover)

## Borders
- `--border` (Subtle borders)
