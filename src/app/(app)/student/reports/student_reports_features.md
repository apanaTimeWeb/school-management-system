# Student Reports — Feature Map

## Module Purpose
The Student Reports module (`/student/reports`) provides a consolidated hub for generating and downloading specific, scoped analytical statements for the student. It covers 8 distinct categories as requested: Attendance, Academic, Result, Assignment, Homework, Fee, Library, and Certificate status.

## Directory Structure
| Folder | Responsibility | Key Files |
|---|---|---|
| `student_reports_components/` | Visual UI: Grid of report cards, Preview Modal | `StudentReportsMain.tsx`, `StudentReportModal.tsx` |
| `student_reports_api/` | Fetches report availability configs | `student_reports_api.ts` |
| `student_reports_types/` | Data interfaces for report configs | `student_reports_types.ts` |
| `student_reports_constants/` | Mock data for UI testing | `student_reports_constants.ts` |

## User Flows & Interactions
### Flow 1: Previewing a Report
1. The user visits the Reports page.
2. They click the "View" button on the "Result Report" card.
3. The `StudentReportModal` mounts as a centered overlay with a backdrop blur.
4. The user sees a mocked A4 paper rendering showing school headers and student details. 
5. The user can either close the preview by clicking the 'X' or click the "Download Full PDF" button in the modal footer.
